# Stage-2 Manual Validation Guide

1. Confirm Stage-1 tests still pass.
2. Confirm Stage-2 code exists only under `src/ftv/source_intake`.
3. Register a source reference with URI, origin label, actor, and metadata.
4. Validate the source.
5. Capture provenance evidence.
6. Mark rights pending.
7. Record a known rights decision.
8. Approve the source manually only after usable known rights exist.
9. Confirm rejected/expired/unknown/pending rights cannot be approved.
10. Confirm no Asset Registry, Duplicate Detection, or Media Processing code was introduced.
