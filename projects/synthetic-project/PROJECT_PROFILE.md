# Synthetic Project Profile

Project id: `synthetic-project`

Project name: Synthetic Project

Layer: CMS project profile

Purpose: Provide a second safe project identity for CMS project-resolution and runtime-context validation.

Default characteristics:

- Language: synthetic test fixture only
- Platforms: no publishing connector
- Content formats: none implemented
- Governance: human approval remains authoritative
- Audit posture: preserve accepted CMS/FTV audit and manual-action requirements
- Local storage: use CMS local runtime storage; this profile does not introduce new services or product capabilities

This project is intentionally non-operational. It exists so CMS can prove project-aware architecture without building TKIC, research, market intelligence, AI, or autonomous publishing behavior.
